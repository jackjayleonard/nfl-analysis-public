As part of my university curriculum, I learned how to create an algorithm in Python that uses data from a single season
of the National Football League (2025-2026) to accurately determine how each team performed over the course of that season.

The files in this repository are the results of my work on that assignment. I was unable to fully finish my work on the algorithm,
but I spent a lot of time refining the model that I had created to more accurately and efficiently quantify each NFL team's performance.
In doing so, I've learned a lot on how to code with Python and its very useful data science packages.

I first conceptualized this project in 2022, before I was accepted into BYU, using Microsoft Excel to create and display my work.
I've come a long way ever since. Feel free to examine my work!
